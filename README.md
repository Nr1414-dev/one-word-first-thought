## The word

**cleave** — one word, six letters. It means its own exact opposite:
to split apart, and to cling together. Surprising, vivid, and carrying
the maximum double meaning a single word can hold.

## How it works

`main.py` writes exactly that one word to `/output/entry.txt`
(UTF-8, 1–24 characters, no trailing newline), with mode `0644`
so the grader can read it.

```sh
python3 main.py
cat /output/entry.txt   # cleave
```
